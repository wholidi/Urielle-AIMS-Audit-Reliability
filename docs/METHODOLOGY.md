# Methodology — Week 1 status

**Scope:** ISO/IEC 42001 Clause 4.3 / C4-Q03. This research evaluates whether specific evidence supports specific AIMS scope claims; it does not assess complete ISO conformity.

The validated dataset contains 20 synthetic cases (five each in **SUPPORTED**, **INSUFFICIENT**, **CONTRADICTED**, **IRRELEVANT**) with 23 integrity-verified evidence files. Labels were assessed in two research-lead calibration/practice exercises, reconciled for disagreements and corrected against cited evidence passages. This is not independent inter-rater validation.

The unchanged deterministic baseline has no independent semantic evidence-consistency check in the assessed decision path. Operational acceptance is not semantic correctness. A proposed prospective scoring amendment maps an `EVIDENCED` state to an operational **ACCEPT** outcome, which will be evaluated against restricted research-lead-calibrated reference labels. The scoring protocol must be approved before numerical results are reported.

**No Phase 2 experimental results are included in this initial repository.** Claims, labels, denominators, experiment conditions and environment details must be pinned before analysis. Data and code made public later require a separate privacy and leakage review.
